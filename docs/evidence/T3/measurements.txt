T3 measurements. Unity 6000.4.0f1, Play Mode, Editor. Game time from Time.time.
Method: taps from the Editor update loop, not from eval, so the stamps are taken between frames (frame delta about 6.6 ms, about 150 fps).
Fields read: TileView, MatchPopup, MatchController, MatchEffects and MatchHud verification properties. The game does not read them.
Design values are from docs/GAME_DESIGN.md (Motion). Measured values are within one frame of the design unless noted.
